# Mana Trendz Macha

Storefront for **Mana Trendz Macha** — neighbourhood men's wear across Telangana and Andhra. Conversion is WhatsApp and walk-in. There is no checkout.

Live: [mana-trendz-macha.vercel.app](https://mana-trendz-macha.vercel.app)

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Branch phones and maps live in `data/stores.ts` (from the official Instagram bio).
- WhatsApp defaults to the Kukatpally line. Override with `NEXT_PUBLIC_WHATSAPP_E164`.
- Hero looks are high-res menswear photography. Instagram stills are used in the lookbook strip.
- Price and size are confirmed in store or on WhatsApp — they are not listed on the site.
