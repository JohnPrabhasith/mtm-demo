# Mana Trendz Macha

Preview storefront for **Mana Trendz Macha** — a local Indian fashion retailer. The site is a client demonstration focused on brand, catalogue browsing, store discovery, and WhatsApp enquiries. Checkout is intentionally not implemented.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Product, store, and photography data live in `/data` and `/config/site.ts`.
- WhatsApp number is configurable via `NEXT_PUBLIC_WHATSAPP_E164`.
- Official logo, live store details, and policies are placeholders until the client confirms them.
